# 우리집식당 화면 구현 전달 패키지

## 구성

- `01_home_corrected.png`: 로그인 홈
- `02_my_table.png`: 내 식탁
- `03_calendar.png`: 달력
- `04_records.png`: 기록
- `05_hamburger_menu.png`: 햄버거 드로어
- `06_notifications.png`: 알림 패널
- `07_household_selector.png`: 우리집 선택 팝오버
- `08_create_meal.png`: 식사 만들기
- `09_empty_home.png`: 홈 빈 상태
- `CODEX_START_PROMPT.md`: 코덱스에 전달할 전체 작업 지시문

## 사용 방법

1. 이 ZIP을 코덱스 작업공간에 전달한다.
2. 최종 PRD와 Ponytail `SKILL.md`가 있다면 함께 전달한다.
3. `CODEX_START_PROMPT.md`의 내용을 작업 요청으로 사용한다.
4. 9장의 이미지는 9개의 독립 사이트가 아니라 5개 페이지, 3개 패널, 1개 상태 화면의 참고 시안이다.

이미지의 음식 사진이나 작은 문구보다 화면 구조, 정보 순서, 내비게이션 위치를 우선해서 구현한다.
