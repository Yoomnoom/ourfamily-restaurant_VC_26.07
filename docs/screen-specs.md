# 화면 목업 안내

`docs/design/`에는 원본 디자인 목업(`E:\ai_바이브코딩\Yoom\수업34일차_우리집식당_임시디자인2`)을 그대로 복사해왔다. 폴더명은 원본과 동일한 번호 체계(1-1, 2-2, 3-0 ... 8-4)를 그대로 쓴다. `docs/viewer.html`에서 왼쪽 목록으로 전부 확인 가능하다.

각 화면 옆에 표시되는 태그의 의미:

- **(구현)**: 지금 실제 앱(`app/`)에 해당 화면·흐름이 있다.
- **(부분 구현)**: 비슷한 기능은 있지만 화면 구성이 다르다 (예: 가구 설정은 별도 페이지가 아니라 팝오버+구성원 패널로 되어 있음).
- **(미구현)**: 이번 단계에 아직 안 만들었지만 범위 안이다 (예: 확정 전 요약, 오늘의 식탁 완성 — 지금은 확정 버튼 한 번으로 즉시 처리됨).
- **(범위 밖)**: `CODEX_PRODUCTION_HANDOFF.md` §12에서 이번 단계 제외로 명시한 기능 (냉장고 AI, 밀키트, 사진 기록, 예산, 정산, 요일별 기본 응답). 참고용으로만 남겨둔다.

목업 HTML은 Tailwind CDN을 그대로 쓰고 있어 인터넷 연결이 있어야 스타일이 정상적으로 보인다. 실제 앱 코드에는 이 CDN을 쓰지 않는다(정적 스크립트는 프로덕션에 부적합해서 순수 CSS로 옮겨 구현했다).
