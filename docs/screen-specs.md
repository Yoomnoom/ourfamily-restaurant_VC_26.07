## 화면 목록과 스펙

### 1. 로그인 — 완료됨 (참고만)
이미 실제 코드로 구현됨. 이메일 입력 → "로그인 링크 받기" → 전송 완료 카드. 하단에 "지문/패스키로 로그인" 버튼.

### 2. 온보딩 — 가구 시작하기
- 상태 A: 가구 만들기 폼 (가구 이름 입력 1개, 버튼 "가구 만들기")
- 상태 B: 초대 코드로 참여 폼 (코드 입력 1개, 버튼 "코드로 참여하기")
- 두 폼을 한 화면에 세로로 두거나, 탭/토글로 분리 — 자유롭게 제안해도 좋음

### 3. 홈 — 오늘 식사 있음
- 인사말: "좋은 저녁이에요, {이름} 님"
- 오늘의 식사 카드: 메뉴명, 날짜/시간, "N명 먹어요 / N명 안 먹어요 / N명 확인 전" 집계, "먹어요"/"안 먹어요" 버튼 (내가 아직 응답 안 했을 때) 또는 "현재 인원으로 확정" 버튼 (내가 응답했고 아직 open 상태일 때)
- 미응답자 있으면: "N명이 아직 응답하지 않았어요" + "미응답자에게 알리기" 버튼
- 하단: "앞으로 예정된 식사 N개" 스트립, "가족이 먹고 싶어 해요" 메뉴 요청 리스트, "지난 식사 다시 만들기" 스트립

### 4. 홈 — 빈 상태 (오늘 식사 없음)
- 빈 상태 카드: 아이콘, "오늘 열린 식사가 없어요", "식사를 만들면 가족에게 누가 먹는지 바로 물어볼 수 있어요", "오늘 식사 만들기" 버튼
- 하단 스트립들은 동일하게 유지

### 5. 내 식탁
- 페이지 헤더: "내 식탁" / "내가 만들거나 참여하는 식사"
- 식사 카드 여러 개를 세로로 나열 (3번 스펙의 카드와 동일한 구조, 여러 개)
- 빈 경우: "아직 만든 식사가 없어요" 텍스트만

### 6. 식사 달력
- 월 헤더 ("2026년 8월"), 이전/다음 버튼(비활성 느낌 OK)
- 7×N 요일 그리드, 식사가 있는 날에는 작은 점 + 메뉴명 표시, 오늘 날짜는 강조 테두리
- 하단: 오늘 날짜 상세 카드 (오늘 식사 있으면 메뉴/시간, 없으면 "오늘은 열린 식사가 없어요")

### 7. 식사 기록
- 통계 카드 3분할: "함께 먹은 식사 N번", "평균 참여 N명", "자주 먹은 메뉴 {메뉴명}"
- 확정된 식사 카드 리스트 (날짜, 메뉴, "N명 함께 먹었어요", "같은 구성으로 만들기" 버튼)

### 8. 식사 만들기 (폼)
- 진행 표시줄
- 식사 종류 세그먼트 버튼 3개: 집밥/외식/배달
- 입력: 날짜, 시간, 메뉴, 메모(선택)
- 참여자 목록 (가구 구성원 이름 + 체크 표시, 읽기 전용)
- 제출 버튼: "식사 만들고 링크 보기"

### 9. 식사 만들기 — 완료 (링크 공유)
- 완료 마크, "식사를 만들었어요", "가족에게 이 링크를 보내주세요"
- 링크 텍스트 표시 + "링크 복사하기" 버튼, "홈으로" 버튼

### 10. 게스트 응답 (비로그인, 공유 링크로 들어온 화면)
- 상단에 로그인 사용자용 내비게이션 없음 (완전히 독립된 화면)
- 날짜/시간, "{메뉴}, 함께 먹을까요?", "회원가입 없이 30초면 답할 수 있어요"
- 폼: 이름, 참여 여부(먹어요/안 먹어요 라디오 pill), 도착 시간, "응답 보내기"

### 11. 게스트 응답 — 제출 완료
- 완료 마크, "응답을 전했어요", "{이름} 님은 {메뉴}를 {먹어요/안 먹어요}"
- "응답 수정하기" 버튼

### 12. 게스트 응답 — 링크 오류
- "링크를 찾을 수 없어요", "만료됐거나 잘못된 링크예요"

### 13. 알림 패널 (오버레이, 오른쪽에서 슬라이드)
- 헤더: "알림", "모두 읽음" 버튼, 닫기(×)
- 리스트: 안 읽은 항목(굵게, ! 아이콘) / 읽은 항목(흐리게, ✓ 아이콘), 각각 텍스트+상세+시간

### 14. 전체 메뉴 드로어 (오버레이)
- 그룹: 가족과 가구(가족 구성원), 반복 설정(4개 항목, 비활성 자리표시자 OK), 살림과 제안(2개, 비활성 OK), 서비스(지문 로그인 등록, 계정 설정, 도움말, 개인정보 및 데이터 — 계정설정/도움말/개인정보는 비활성 자리표시자 OK)
- 맨 아래: 로그아웃 버튼

### 15. 가구 선택 팝오버
- 가구 목록 (이름 + 체크마크로 현재 선택 표시)
- "새 가구 만들기", "초대 코드로 참여" 버튼

### 16. 가족 구성원 패널
- 구성원 리스트: 이름 첫글자 아바타, 이름, 역할 배지(오너/공동 관리자/구성원)
- 관리자만 보임: 구성원별 "내보내기" 버튼, "초대 코드 만들기" 버튼

## 공통 상단바 / 하단 내비게이션 (3~9번 화면에 적용)

상단: 왼쪽 브랜드(우리집식당), 가운데 가구 선택("우리집 ⌄"), 오른쪽 알림 벨 + 햄버거
하단: 홈 / 내 식탁 / (가운데 돌출) + 식사 만들기 / 달력 / 기록 — 정확히 이 순서, 5개 고정
